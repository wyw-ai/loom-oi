# 知识库入口

KB提供来源、结论和决定的索引，不替代原件、当前设计或GitHub评论。

| 需要什么 | 入口 | 使用边界 |
| --- | --- | --- |
| 原始来源和核对范围 | [证据台账](evidence.md) | 引用可追溯版本；重复上传不增加证据 |
| 技术事实和设计推论 | [结论索引](conclusions.md) | Supported不等于已采用，窄实验不外推整套产品 |
| 人类决定和工作授权 | [决策台账](decisions.md) / [ADR索引](../docs/decisions/README.md) | 原回复为依据，只覆盖准确范围 |
| 阶段与旧方向 | [经验血缘](lineage.md) / [Issue快照](../docs/issue-history/README.md) | 先查假设、结果、停止原因与重启条件；只追加纠正，历史缺口不补造 |
| 已出现的协作缺陷 | [经验](lessons.md) | 规则应解决实际问题，不堆叠泛化口号 |
| 当前方案和评审 | [架构](../docs/architecture/alpha-v0.7.md) / [Issue导航](../docs/alpha-issues.md) | KB不维护另一份完整方案 |
| 实验和报告 | [实验室](../experiments/README.md) / [证据报告](../docs/evidence/README.md) | 原始记录、预注册、ITER和门槛分别使用 |

条目保留稳定ID、类型、来源/范围与替代关系；过时的是结论时修正当前条目，历史推导通过固定提交或证据报告追溯。明确区分Fact、Intent、User decision、Proposal、Hypothesis和已替代。更新细则遵循[结构规范](../docs/structure.md)，执行由[架构 Partner](../.agents/skills/architecture-partner/SKILL.md)负责。
