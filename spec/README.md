# 任务规格入口

本目录只维护每项任务的方案、确认、实施子步骤和交付验证；长期现行契约仍在 `docs/`，内容职责见[结构规范](../docs/structure.md)。执行[开发流程规范](../docs/sdd/development-workflow.md)，创建任务时复制[模板](_template/README.md)。

一个任务一个目录、一个 `feature/<任务ID>-<简述>` 分支、一个 MR。模板不是实际任务；已完成任务的当时证据保留，后续变化另建任务，不覆盖历史验证结果。此入口只导航，不复制状态或方案。
