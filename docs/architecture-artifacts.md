## 绘图渠道与视觉标准

2026-11-02用户明确要求：后续ImageGen等专业渠道可用时优先使用，以提高视觉效果。此为持续绘图偏好；v0.7采用Graphviz不代表以后固定只用Graphviz。

1. 每次创建或更新图前，检查当轮可用的专业生成/设计渠道及其适用范围，不沿用旧轮次的可用性判断。适合生成式视觉的展示图、概念插图与视觉素材优先使用ImageGen；重视构图、层级和整体呈现质量。
2. 必须精确表达的架构拓扑、状态/时序、接口和实验数据，使用能确定并校验节点、连线与数值的专业矢量/图表渠道。可配套生成式视觉素材提升表现，但精确信息以结构源与正式契约为准。
3. 视觉交付优先中文可读说明与准确技术名词；统一字体、字号层级、配色、图例、间距和分组，减少长文本堆叠、交叉连线、遮挡及过度横向拉长。不能仅以“成功渲染”认定视觉质量合格。
4. 图生成后逐张检查组件职责、箭头端点/方向、控制与数据关系、信任/存储边界、可选项及采用/实验状态；发现幻觉、漏字、错线或低可读性先修订再交付。保存源定义或提示词、所用渠道、修订记录与最终产物，图文同步。
5. 优先渠道不可用或不适合当前精确性要求时，使用合适的专业替代并如实记录原因。后续绘图重新评估渠道，不将替代永久化，也不把未调用的ImageGen写成实际生成来源。

本次只记录后续工作要求，不重绘现有图、不改变架构或实验结论。
