## 取舍与后续观察

C1保留无探针服务的可接入性，代价是Unknown尝试不能提供就绪保证；C2减少首版运维复杂度，代价是实例/主机故障会中断服务且迁移有维护窗口；C3让R先形成可验证闭环，H按收益研究，代价是当前不承诺跨路径不断流。

按原回复持续观察端到端准入、连接成功与失败、恢复、资源及维护成本，观察项目见[本轮清单](../evidence/implementation-readiness-004.md#observations)，随对应实现节点和真实实验更新。出现越权、串目标、旧状态复活或隐式业务重放，不用平均性能抵消；需求或证据改变时按现有Issue流程复评相应范围。

方向采用不放行G0–G7，不替代具体任务方案、实施授权、真实实验和交付验收；本页不是“整份架构全部通过”的凭据。
