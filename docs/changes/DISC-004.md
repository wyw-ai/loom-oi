## 2. 求解后发生什么变化

- **主体先于组件**：补齐谁使用、整体价值、职责与外部边界；从外部基础、接入对象、共同契约、路径/诊断到消费体验逐层说明可兑现和不可凭空增加的能力。它是概念依赖，不是强制五个服务。
- **双向推导**：从用户结果到契约/路径/负载/部署，再由机制的权限、状态、失败及总代价核对整体承诺。每轮DISC记录实际保持/改变和跨产物影响，轻微编辑允许简述无影响，不增加审批层。
- **主问题内求解**：#15保留R实现/实验基线，同时比较H新Open路径选择及有界准备回退；已打开通道失败后新建，不自动重放；M明确为有额外状态成本的条件性备选。不要求先采用H才研究，不要求穷尽P2P才推进R。
- **由实际路径推导部署**：以B_R统计真实中继双向载荷，控制/两端/探测重试另计。A/B/C由端到端成本和故障要求判断，不把“减少中继字节”“独立进程”“消除控制权威”混成同一种收益。
- **保留有效证据边界**：现有采用、运行数据、真实物料和实验门槛均不改变。新方案是推演，缺实现/代表拓扑/预算/故障环境；不制造实验run、ITER或性能结论。
