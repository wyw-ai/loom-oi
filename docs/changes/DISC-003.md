## 2. 为什么旧确认目标失效

r1虽区分中心控制/转发/存储并给出故障机制，却将#15确认限定为A同进程或B拆进程，将D/H继续留作以后触发的其他方向。路径会改变实际中继字节及故障前提，不能先冻结部署再研究这一变量。用户W19纠正后，DISC-003-R1标为Deferred，由DISC-004-R2完整路径/负载/部署方案替代；不是接受或实现旧A/B推荐。

原r1完整分析、图与检查结果见[固定版本](https://github.com/wyw-ai/loom-oi/blob/3d21e2f375c6ee87d3abe69402984755a9786952/docs/changes/DISC-003.md)。旧V01曾通过文档/引用核验，不表示语义分解正确；旧V02无产品运行，验证设计由新范围承接。原实验、评论和采用凭据保留。
