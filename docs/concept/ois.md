# OIS：能力目录、策略与可信中继

状态：H8已确认R中继和PG/SQLite要求；具体契约评审中，见[当前架构](../architecture/alpha-v0.7.md)。

OIS由OI部署管理方维护，认证接入方和消费者，维护目录与访问策略，协调通道并配对双方出站数据腿。目录可见不等于访问获准；管理权限与原生服务的业务权限分别验证。

持久化保存管理元数据，默认推荐PostgreSQL，无PG部署可显式选择SQLite。连接、通道和就绪观测不当作可恢复业务会话；PG故障不自动切换SQLite。SQLite单实例和PG主备具有不同验证范围。

OIS不编排Agent决策、记忆、任务或功能实例，不解析任意bash命令，也不以通道结果推断命令是否执行。可信中继会终止对应传输层；业务要求中继不可读时应另行明确端到端协议和身份验证。

[模块规格](../modules/ois/README.md)细化目录、授权、中继和存储的责任；主备和恢复必须经过[G0–G7](../../experiments/GATES.md)相应验证，不由语言或多副本数量保证。
